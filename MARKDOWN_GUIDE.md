# Markdown Syntax Reference

This file is a practice guide to common Markdown syntax used in GitHub documentation.

## Headings

# Heading 1 (largest)
## Heading 2
### Heading 3

## Text Formatting

**Bold text**  
*Italic text*  
~~Strikethrough~~

## Unordered Lists

- Item A
- Item B
  - Nested item B1

## Ordered Lists

1. First step
2. Second step

## Inline Code

Use inline code for short commands or snippets: `print("Hello")`

## Fenced Code Block

Use a language label for syntax highlighting:

```python
def greet(name):
    return f"Hello, {name}!"
```
